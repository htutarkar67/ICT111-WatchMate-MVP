# User Testing Plan

> [!NOTE]
> **Status Note:** Formal user testing sessions and testing forms were **not conducted** for this prototype phase. This document serves as a theoretical testing framework and specification for future evaluation.

## 1. Testing Objective

The objective of this user testing plan is to evaluate the usability, recommendation quality, user flow efficiency, task completion rate, and feature clarity of **WatchMate – AI Movie Recommendation System** prior to the final project presentation. Specifically, testing aims to verify whether users can easily register or log in, receive personalized AI movie recommendations, search for movies, view movie details, save movies to a watchlist, and navigate the system without confusion.

## 2. Test User Profile

| User Type | Number of Testers | Why This User Type Matters |
| --- | --- | --- |
| Target Users (Students & Movie Lovers) | 15 Testers | University students and movie enthusiasts who regularly watch movies and want personalized recommendations. |
| Administrator | 5 Testers | System administrators responsible for managing movie information, categories, and recommendation data. |

## 3. Testing Tasks

| Task ID | User Task | Related Requirement | Success Criteria | Observation Focus |
| --- | --- | --- | --- | --- |
| **T01** | Register a new account or log in to the system. | FR-01, FR-02 | User successfully accesses the system without assistance. | Login flow, navigation clarity, and ease of access. |
| **T02** | Enter movie preferences or interact with the AI chatbot. | FR-03 | User provides preferences and understands how the AI recommendation process works. | Input clarity, chatbot usability, and response understanding. |
| **T03** | Search for a movie using keywords or genres. | FR-05 | User successfully finds a movie using the search feature. | Search speed, filter usability, and search result relevance. |
| **T04** | View movie details and recommendation results. | FR-05 | User understands the movie information and recommendation results. | Information layout, readability, and recommendation quality. |
| **T05** | Save a recommended movie to the watchlist. | FR-04 | User successfully adds a movie to the watchlist. | Ease of interaction and confirmation feedback. |
| **T06** | Access the administrator dashboard and update movie information. | FR-04, FR-05 | Administrator successfully manages movie records. | Navigation, management workflow, and usability of admin features. |

## 4. Testing Procedure

1. **Introduction:** Explain that the purpose is to evaluate the prototype, not the participant's performance.
2. **Task Execution:** Ask participants to complete Tasks T01–T06 while thinking aloud.
3. **Observation:** Observe user interactions without providing assistance unless they are unable to continue.
4. **Recording Results:** Record task completion (Completed, Partial, or Failed), completion time, usability issues, and participant comments.
5. **Feedback Collection:** Ask participants to rate the system's ease of use, recommendation quality, and overall satisfaction, then collect improvement suggestions.

## 5. Ethical & Responsible Data Protection

- **Data Minimization:** No real passwords, payment information, or sensitive personal information will be collected during testing.
- **Privacy Protection:** Test accounts and sample movie preferences are used only for prototype evaluation.
- **Consent:** Participants are informed that all feedback is collected solely for academic purposes and prototype improvement.
- **Confidentiality:** Individual participant responses will remain anonymous and will not be shared outside the project team.
