# Final Reflection

## 1. What We Built

Our team built **WatchMate**, an AI Movie Recommendation System that helps users discover movies based on their preferences. The prototype allows users to create an account, log in, select their favorite genres and preferences, receive AI-generated movie recommendations, search for movies, view detailed movie information, manage a personal watchlist, and review their recommendation history through a simple and user-friendly interface.

---

## 2. What We Learned About Users

- **Users Prefer Personalized Recommendations:** Many users want movie suggestions based on their interests instead of browsing long movie lists.
- **Simple User Experience Matters:** Users preferred a clean interface where they could quickly receive recommendations without completing too many steps.
- **Movie Information Is Important:** Users wanted to see ratings, genres, release year, synopsis, and trailers before deciding what to watch.
- **Saving Movies Is Useful:** Users appreciated having a watchlist so they could save interesting movies for future viewing.

---

## 3. What We Learned About Requirements

- **Clear Functional Requirements Improve Development:** Defining the system requirements before implementation helped us organize the prototype and connect each feature to a specific user need.
- **Prioritizing Core Features Was Important:** Instead of adding many advanced features, we focused on completing the essential recommendation, search, movie details, and watchlist functions.

---

## 4. What We Improved After Testing

After reviewing our prototype, we made several improvements:

- Improved the homepage layout and navigation.
- Simplified the movie preference selection process.
- Enhanced the recommendation results page for better readability.
- Improved the movie detail page by displaying more useful information.
- Refined the search function to help users find movies more easily.
- Improved the watchlist interface for better usability.

---

## 5. What Was Difficult Technically

- Designing an intuitive interface that works well on both desktop and mobile devices.
- Organizing movie information and recommendation results in a clear layout.
- Maintaining consistency across multiple prototype screens.
- Managing the relationship between user preferences and recommendation results within the prototype.

---

## 6. What We Would Improve Next

In future development, we would like to:

1. Integrate a real AI recommendation engine using machine learning.
2. Connect the system to an online movie database API for real-time movie information.
3. Allow users to rate movies and improve future recommendations.
4. Add social features such as sharing recommendations with friends.
5. Develop a mobile application version of WatchMate.
