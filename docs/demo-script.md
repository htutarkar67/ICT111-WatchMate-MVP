# Demo Script

## Demo Objective

Demonstrate how **WatchMate** helps users discover movies through an AI-powered recommendation chatbot, search for movies, view detailed movie information, save movies to a watchlist, and allow administrators to monitor user chatbot conversations through the admin dashboard.

## Demo Flow

| Step | Screen / Feature | What Presenter Says | Requirement ID | Expected User Value |
| --- | --- | --- | --- | --- |
| **1** | Landing/Homepage | Introduce WatchMate, explain the target users, and describe how AI helps users discover movies more easily. | FR-01 | Users immediately understand the purpose of the platform and how to begin. |
| **2** | AI Chatbot | Demonstrate how users enter their movie preferences and receive personalized recommendations from the AI chatbot. | FR-02, FR-03 | Users receive personalized movie recommendations based on their interests. |
| **3** | Movie Search | Show how users search for movies by title and browse trending movies and TV shows. | FR-05, FR-06 | Users can quickly find movies they want to watch. |

| **7** | Dashboard & Analytics | Present the Power BI dashboard showing user testing results, recommendation statistics, and usability metrics. | FR-12 | Provides insights into user behavior and system performance. |
| **8** | Closing | Summarize the project's value, achievements, and future improvements for the AI recommendation system. | FR-16 | Demonstrates how WatchMate solves the movie discovery problem through AI. |

---

## Closing Statement

WatchMate makes movie discovery faster, easier, and more personalized by combining AI-powered recommendations with comprehensive movie information in one platform. Instead of spending time searching across multiple websites, users can simply chat with the AI assistant, receive tailored recommendations, explore movie details, and save their favorites. With continuous improvements based on user feedback, WatchMate aims to become a reliable companion for anyone looking for their next movie to watch.
