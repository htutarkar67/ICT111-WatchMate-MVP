# Final Demo Script

## Demo Duration
Recommended duration: **5–7 minutes**

---

## 1. Opening

Introduce the project:

- **Project Title:** WatchMate – AI Movie Recommendation System
- **Problem:** Many users spend too much time searching through streaming platforms without knowing what to watch.
- **Target Users:** Students, movie enthusiasts, and casual viewers looking for personalized movie recommendations.
- **Value Proposition:** WatchMate uses AI to recommend movies based on user preferences, making movie discovery faster, easier, and more personalized.

---

## 2. User Scenario

Imagine a student wants to watch a movie after class but doesn't know what to choose. Instead of browsing hundreds of movies, the student opens **WatchMate**, selects their preferred genres and mood, and instantly receives personalized movie recommendations with detailed information and trailers.

---

## 3. Prototype Walkthrough

| Step | Screen / Feature | What to Demonstrate | Requirement ID |
|---|---|---|---|
| 1 | Homepage | Introduce the project, target users, and click **Get Started** | FR-01 |
| 2 | Login / Register | Demonstrate user login or account registration | FR-02 |
| 3 | Movie Preference Form | Select favorite genres, mood, language, and preferences | FR-03 |
| 4 | AI Recommendation | Generate personalized movie recommendations | FR-04 |
| 5 | Search Results | Browse and filter recommended movies | FR-05 |
| 6 | Movie Details | Display synopsis, rating, cast, and trailer | FR-06 |
| 7 | Chat History | Show previous AI recommendation conversations | FR-07 |
| 8 | Watchlist | Save recommended movies for future viewing | FR-08 |
| 9 | Admin Dashboard | Display recommendation statistics and user activity | FR-09 |

---

## 4. Evidence and Validation

Briefly explain the project evidence:

- Demonstrate sample recommendation records and activity logs.
- Present user testing results and feedback collected during prototype evaluation.
- Show startup metrics such as landing page views, AI recommendation requests, and user satisfaction.
- Explain how feedback was used to improve the prototype.

---

## 5. Closing

Summarize the project:

- WatchMate helps users discover movies quickly through AI-powered personalized recommendations.
- The prototype successfully demonstrates the core recommendation workflow, search functionality, watchlist management, and movie information features.
- Future improvements include integrating real AI APIs, connecting to live movie databases (such as TMDb), supporting multiple streaming platforms, and enhancing recommendation accuracy through machine learning.
