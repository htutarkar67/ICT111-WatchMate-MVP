## Summary

### Strengths
- Users found the AI chatbot helpful for discovering new movies.
- Movie search and detail pages were easy to use.
- The admin dashboard successfully displayed user chat history.
- The homepage clearly communicated the system's purpose.

### Areas for Improvement
- Improve AI response speed.
- Make the Watchlist button more visible.
- Enhance recommendation accuracy for mood-based requests.
- Simplify movie filter navigation.
- Improve genre filtering and search usability on mobile devices.

### Overall Result

The user testing results indicate that **WatchMate successfully supports the core MVP features**, including AI-powered movie recommendations, movie search, detailed movie information, watchlist management, and administrator chat history monitoring. User feedback also identified several usability improvements that will guide future development.
