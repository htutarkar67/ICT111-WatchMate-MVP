## Specifications

- **Prototype Platform / Tool:** HTML5, CSS3, JavaScript (Frontend Web Prototype)
- **Prototype Location:** `prototype/`
- **Login / Access Instructions:** No login is required for demonstration purposes. Users can explore the homepage, register or log in, interact with the AI chatbot, search movies, view movie details, manage their watchlist, and browse recommendation history. Administrator features can be accessed through the Admin Dashboard.
- **Supported Features:**
  - Homepage
  - User Registration
  - User Login
  - AI Chatbot
  - AI Movie Recommendations
  - Movie Search
  - Movie Details
  - Watchlist Management
  - Chat History
  - Admin Dashboard

## Notes for Lecturer

This prototype demonstrates the core functionality of the **WatchMate – AI Movie Recommendation System**. It includes representative sample movie data to simulate AI-powered recommendations, movie searching, recommendation history, and watchlist management. The prototype is intended for demonstration and validation of the user interface, user experience, and functional requirements developed throughout the ICT111 course.
