# WatchMate: AI Movie Recommendation System

Welcome to the **WatchMate** prototype! WatchMate is an AI-powered movie recommendation system that helps users discover movies and TV shows through an intelligent chatbot. Users can browse trending content, search for movies, receive personalized recommendations, save movies to a watchlist, and review previous AI conversations.

## Roles to Explore

### 🎬 Guest User

Visitors can:

- Browse trending movies and TV shows.
- Search for movies by title.
- Chat with the AI assistant for personalized movie recommendations.
- View movie details, ratings, genres, and trailers.

---

### 👤 Registered User

After logging in, users can:

- Continue chatting with the AI assistant.
- View previous chat history.
- Save movies to their watchlist.
- Manage their personalized movie recommendations.

---

### 👨‍💼 Administrator

Administrators can:

- View user AI chatbot conversations.
- Monitor chatbot usage.
- Review recommendation history.
- Access the dashboard for chatbot analytics and system activity.

---

## Main Features

- 🤖 AI-powered movie recommendation chatbot
